Kebijakan Privasi Rclone Pribadi

Terakhir diperbarui: 7 November 2026.

Penggunaan data Google Drive

Rclone Pribadi digunakan untuk mengelola akun Google Drive yang diizinkan oleh pemiliknya. Akses mencakup daftar dan isi file, unggah, unduh, pengubahan, dan penghapusan sesuai tindakan pengguna. Data tidak dijual atau digunakan untuk iklan maupun pelatihan AI.

Penyimpanan dan transfer

Rclone berkomunikasi langsung dengan layanan Google. Token akses dan konfigurasi disimpan pada komputer pengguna. Cache lokal dapat menyimpan isi file untuk mendukung transfer. Website ini tidak menerima atau menyimpan token maupun file Google Drive.

Website dihosting melalui GitHub Pages. GitHub dapat memproses data kunjungan sesuai kebijakan privasi GitHub.

Pencabutan izin dan penghapusan lokal

Izin dapat dicabut melalui koneksi akun Google. Pencabutan izin tidak otomatis menghapus konfigurasi, cache, atau salinan file lokal; pengguna perlu menghapusnya secara terpisah.

Kontak

Hubungi pengelola melalui GitHub Issues. Jangan sertakan kredensial atau data pribadi.
